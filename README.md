# Цели и цитаты 3.0 («Путь»)

Android-приложение на Kotlin + Compose. Пять вкладок: **Путь**, **Цели**, **Цитаты**, **Заметки**, **Ещё**.
Сборка APK: GitHub Actions (`.github/workflows/build.yml`), готовый файл лежит в ветке `apk-build`.

## Как устроено
| Что | Где |
|---|---|
| Сцена «Путь» (three.js, офлайн) | `app/src/main/assets/path/index.html`, библиотеки в `assets/path/lib`, шрифты скачиваются при сборке |
| Мост сцена ↔ приложение | `PathScreen.kt` (`PathBridge`: `load`, `save`, `today`, `pending`, `ack`) |
| Состояние сцены | один JSON в SharedPreferences (`path_state`), сцена сохраняет его сама и восстанавливается из него |
| Цели и цитаты | `MainActivity.kt` (`ItemsScreen`, `RemindersSection`): напоминаний сколько угодно, в заданное время или с интервалом |
| Заметки по датам | `NotesScreen.kt`, необязательное напоминание в выбранное время |
| Будильники | `Scheduler.kt`: отдельный будильник на каждое напоминание, при любом изменении пересоздаются |
| Уведомления и каналы | `Notifier.kt` |
| Мелодии островов | `Melody.kt`: ноты из сцены превращаются в звук флейты в телефоне |
| Мелодия самурая (звук по умолчанию) | `res/raw/samurai_welcome.ogg`, генератор `tools/generate_welcome.py` |
| Демо сцены без сохранения | `DemoActivity.kt` (кнопка во вкладке «Ещё») |

## Дни и отметки
- День считается по календарю телефона с учётом «начала нового дня» (00:00 или 04:00 в «Ещё»).
- При открытии сцена сравнивает сохранённый день с сегодняшним и по очереди проигрывает «новые дни» (пропуски, дождь, красный статус).
- Кнопка «Сделано» в уведомлении рутины записывает отметку в `pending`. Сцена применяет её при открытии: зажигает фонарь за тот день.
- Пока открыта другая вкладка или приложение свёрнуто, сцена приостановлена. Напоминания идут через AlarmManager и от сцены не зависят.

## Правило для звука уведомлений
Звук канала нельзя изменить после создания. Чтобы сменить мелодию по умолчанию: положить новый файл в `res/raw`, увеличить версию ID канала в `Notifier.kt` (`goals_sound_v4` → `v5`) и добавить старый ID в `OLD_CHANNELS`.
Мелодию острова приложение играет само (канал при этом беззвучный), поэтому новых каналов под каждую мелодию не нужно.

## Выбор мелодии по функциям
`Store.sound(fn)`: `welcome` (по умолчанию), `silent` или `m:<id мелодии из сцены>`. Функции: `goals`, `quotes`, `routines`, `notes`.

## Фразы самурая
Приветствие и фраза при поклоне редактируются в сцене («Редактор») и хранятся в состоянии сцены.
